\# School Bus Tracking System



A real-time school bus tracking platform designed to help schools manage buses, drivers, routes, students, and parent communication.



\## Project Components



The project is maintained through four separate repositories:



\- \*\*Backend:\*\* Node.js, Express.js, MongoDB, and Socket.IO

\- \*\*Driver App:\*\* Mobile application for drivers to manage trips and share live GPS locations

\- \*\*Parent App:\*\* Mobile application for parents to track buses and receive notifications

\- \*\*Admin Panel:\*\* Dashboard for managing buses, drivers, students, routes, and trips



\## Features



\- Live bus location tracking

\- Driver trip management

\- Route and pickup-point management

\- Parent notifications and estimated arrival information

\- Administrative dashboard

\- Planned multi-school support with school-specific data isolation
